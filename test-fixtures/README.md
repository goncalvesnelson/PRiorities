# GitHub diff fixtures

Captured on 2026-09-27 without signing in. Only diff containers and the fields needed to interpret them are retained.

- `github-classic.html`: file container from [microsoft/vscode PR #200000](https://github.com/microsoft/vscode/pull/200000/files). Exercises classic unified rows, line anchors, hunk headers and comparison revisions.
- `github-source.json`: source lines from [the pinned head file](https://github.com/microsoft/vscode/blob/9ed10330f92962e92c6b121fd0cf6588268e89a8/src/vs/editor/contrib/suggest/browser/suggestWidgetRenderer.ts). Its `colorizedLines` were rebuilt on 2026-10-01 from that page's public `stylingDirectives` in the `<span class=pl-k>` form that signed-in pages carry; the anonymous page sent `stylingDirectives` instead. Exercises source context extraction and syntax highlighting.
- `github-react.html`: diff containers and selected embedded JSON from [refined-github/sandbox commit c28cc8e](https://github.com/refined-github/sandbox/commit/c28cc8e5271452b5b4c347d46a63f717c29417d6). Exercises the React diff component's real row markup and `diffEntryData` shape. This is a public commit-page capture, not a captured authenticated PR page; PR payload/layout compatibility must remain conservative.
- `github-deferred.mjs`: synthetic 53-file PR with four initial file placeholders, progressive pagination, deferred tabs containing the total file count, and a `data-fragment-url` loader for each file. Models GitHub's deferred diff markup inspected on 2026-09-28 in [CodeGraphContext PR #1728](https://github.com/CodeGraphContext/CodeGraphContext/pull/1728/files); it contains no private PR content. Exercises complete capture beyond 20 fragment requests, count mismatches, and rejection of fragment URLs outside the repository.
- `github-changes.mjs`: synthetic current Changes route with 53 `diffSummaries`, four inline `diffContents`, and four rendered split-view tables. A three-file variant uses current unified `new-diff-line-number` cells and `diff-text-cell` markup. Models the authenticated route inspected on 2026-09-28 without retaining private code, identifiers, or session data. Each row carries GitHub's highlighted `html`. Exercises the `/files` redirect to `/changes`, lazy JSON diff loading for the other 49 files, individual loading of large deferred files, generated files requiring `/page_data/diff_entry_lines`, exact row and revision capture, encoded filenames, and rejection of missing, duplicate, mismatched, or truncated entries before any model request. The unified variant also exercises three concurrent native processes, a final cross-file check, and native folding/restoration.

The extension browser test routes GitHub reads to these fixtures and supplies Codex and Claude Code responses through fake local processes and the real native messaging host. It does not post to GitHub or call a paid model.
