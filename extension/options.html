Uses your existing CLI login. To sign in, run codex login in Terminal, then check the connection again.

Leave blank for Codex’s built-in default, or enter a model ID available to your account. Reviews use isolated sessions with the captured PR context.

Code is sent only when you start analysis.

Analyze PR sends the included diffs and captured context through your selected local CLI.

How reviews run

Up to three files are reviewed at once, then related changes are checked together. Generated files stay out of analysis until you choose Review anyway.

Your login stays with the CLI. No API key or local repository checkout is needed.

Saved reviews

Matching reviews reopen without new model calls. The cache stores review explanations and selected code excerpts on this browser. Changes to commits, captured context, provider or model require a fresh review.

Checking saved reviews…

Default: 100 MB. When full, the least recently used reviews are removed first. You can choose 1–1024 MB.

Try it on a pull request

  1. Choose a connected CLI, save your settings, then open a GitHub PR’s Files changed tab.
  2. Choose Analyze PR in PRiorities.
  3. Read the review decisions, expand supporting evidence, or switch back to the full GitHub diff.

PRiorities does not post comments, approve changes, or mark files reviewed. Its prioritization is a suggestion; all changed code remains accessible.
